# Building

The same CMake project builds for the host (Linux/macOS: development, tests,
desktop preview) and for the PS5 (ps5-payload-sdk).

## Host build

Requirements: CMake ≥ 3.21, Ninja (or Make), a C++20 compiler (GCC 13 or
Clang 16+), pkg-config, and the development packages for libcurl, SQLite 3,
SDL2, SDL2_ttf and SDL2_image.

Debian/Ubuntu:

```sh
sudo apt install cmake ninja-build pkg-config libcurl4-openssl-dev libsqlite3-dev \
                 libsdl2-dev libsdl2-ttf-dev libsdl2-image-dev
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug -DAKENO_WARNINGS_AS_ERRORS=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

Options:

| Option | Default | Meaning |
|---|---|---|
| `AKENO_BUILD_APP` | `ON` | Build the SDL2 user interface and `AkenoModManager`. `OFF` builds only the core library, `AkenoSelfCheck` and the tests (no SDL needed). |
| `AKENO_BUILD_TESTS` | `ON` on host, `OFF` for PS5 | doctest unit tests |
| `AKENO_WARNINGS_AS_ERRORS` | `OFF` | `-Werror` (CI uses `ON`) |
| `AKENO_SANITIZE` | `OFF` | AddressSanitizer + UndefinedBehaviorSanitizer for host builds |

### Running the desktop build

The desktop build talks to a ShadowMountPlus API just like the console. Without
a PS5, use the mock server, which serves fictional demo games and a demo mod
catalogue (`tests/fixtures/catalog`, regenerated with `tools/make_demo_catalog.py`):

```sh
python3 tools/mock_shadowmount.py &                    # 127.0.0.1:10101
./build/src/ui/AkenoModManager --data-root /tmp/akeno \
  --catalogue-url http://127.0.0.1:10101/catalog/      # window 1280x720
```

Without `--catalogue-url` Akeno reads the published catalogue on GitHub, which
has no entries yet.

Keyboard: arrows move, Enter = ✕, Escape/Backspace = ○, Q/E = L1/R1,
T = △, Y = □, Tab/F5 = OPTIONS, Page Up/Down = L2/R2. While a text field
(search) is open, typing goes into the field; Enter accepts, Escape cancels. A connected game controller works through
SDL's GameController API.

Headless modes:

```sh
./build/src/ui/AkenoModManager --self-check --data-root /tmp/akeno
./build/src/ui/AkenoModManager --list-games --data-root /tmp/akeno
./build/AkenoSelfCheck --data-root /tmp/akeno
```

Scripted UI run with screenshots (used by CI):

```sh
SDL_VIDEODRIVER=offscreen ./build/src/ui/AkenoModManager --data-root /tmp/akeno \
  --window 1920x1080 --ui-script "wait:3,confirm,wait:2,next-tab,shot:games,quit"
# -> /tmp/akeno/logs/games.png
```

Script steps: `wait:<seconds>`, an action (`confirm`, `back`, `secondary`,
`tertiary`, `options`, `up`, `down`, `left`, `right`, `prev-tab`, `next-tab`,
`page-up`, `page-down`), `shot:<name>`, `type:<text>` (completes an open text
field) and `quit`.

Validate a catalogue directory:

```sh
./build/akeno-catalog-check catalog                                    # published: https only
./build/akeno-catalog-check tests/fixtures/catalog --allow-loopback    # demo catalogue
```

## PS5 build

Requirements: LLVM/Clang 18+ with LLD (the SDK wrappers use the system
`clang`, `ld.lld` and `llvm-config-NN`), CMake, Ninja, pkg-config, and the
**ps5-payload-sdk with the pacbrew libraries**.

The simplest way to get the SDK and libraries is the prebuilt bundle published
by `ps5-payload-dev/pacbrew-repo`, the same one CI uses:

```sh
sudo apt install clang-18 lld-18 llvm-18 cmake ninja-build pkg-config
curl -fsSLO https://github.com/ps5-payload-dev/pacbrew-repo/releases/download/v0.40.2/ps5-payload-dev.tar.gz
echo "a85f65de418a8e6a898c6c3e3c870d50fff7618a200e4dd59ea9692af6ecec4d  ps5-payload-dev.tar.gz" | sha256sum -c -
sudo tar -xzf ps5-payload-dev.tar.gz -C /     # -> /opt/ps5-payload-sdk
export PS5_PAYLOAD_SDK=/opt/ps5-payload-sdk

cmake -S . -B build-ps5 -G Ninja -DCMAKE_BUILD_TYPE=Release \
      -DCMAKE_TOOLCHAIN_FILE=$PS5_PAYLOAD_SDK/toolchain/prospero.cmake
cmake --build build-ps5
```

Output in `build-ps5/dist/`:

| File | What it is |
|---|---|
| `AkenoModManager.elf` | full application (payload) |
| `AkenoSelfCheck.elf` | headless system check payload for first tests (no video) |
| `AkenoModManager-homebrew.zip` | `AkenoModManager/` folder for the websrv Homebrew Launcher |
| `SHA256SUMS` | checksums of the three files above |

Distributed copies have debug information stripped. The unstripped ELFs stay
in `build-ps5/` for symbolising crash reports.

Only `-DCMAKE_BUILD_TYPE=Release` has been used so far. The build is
**compiled only**: it has not run on hardware yet.

## Continuous integration

`.github/workflows/ci.yml` runs on every push:

* **host**: warnings-as-errors build, unit tests, headless runs against the
  mock API, an offscreen UI smoke test (screenshots uploaded as artifacts);
* **sanitizers**: unit tests under ASan/UBSan;
* **ps5**: downloads and checksum-verifies the pinned SDK bundle, builds,
  verifies `SHA256SUMS`, uploads the PS5 artifacts.
